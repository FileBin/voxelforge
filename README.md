# voxelforge

Воксельный движок на решётке **BCC**. Один бинарь, один мир, одна решётка:
кубических вокселей в движке нет — ячейка это **усечённый октаэдр**, то есть
ячейка Вороного узла BCC.

```
nix run .#world     # снаряд влетает в плиту: она раскалывается, ячейки дробятся
nix run .#viewer    # http://localhost:8080/viewer/index.html, перетащить .vfw
python3 tools/preview.py demos/out/world.vfw --frames 0,12,299 --out demos/out
cargo test --locked # тесты: решётка, раскол, дробление, физика, сверка CPU/GPU
```

`tools/preview.py` рисует кадры (и mp4 через ffmpeg) без браузера — тем же
`.vfw`, что читает вьюер, так что результат можно смотреть и в CI.

## Что происходит в мире

Примитив движка — **тетраэдр**, не куб и не сфера. Кубическая ячейка BCC
(8 углов + центр тела) делится на **12 одинаковых тетраэдров**, и всё
дальше живёт на этой тетраэдральной решётке.

1. Плита — 4×4×4 кубических ячейки = **768 тетраэдров**, шаг решётки **0.28 м**.
2. В неё влетает воксельный снаряд (тоже BCC-ячейки, не шар-примитив).
3. Плита раскалывается по **Вороному**: затравки внутри объёма, каждая ячейка
   достаётся ближайшей. Осколки выходят неровными — тест проверяет, что
   многоклеточные осколки не являются коробками (нарезка сеткой дала бы 100%).
4. Детализация дробится в полёте: **0.28 → 0.14 → 0.07 м** (степени двойки).
   Тетраэдр при red-разбиении даёт ровно 8 детей, объём и масса сохраняются
   бит-в-бит; дробление идёт сразу по всем осколкам, иначе на стыке соседей
   получается T-стык и щель.
5. Всё считается на видеокарте: Vulkan compute через C-ядро. CPU собирает
   сцену, пишет файл и не участвует в физике.

Замер последнего прогона (`--frames 300`, lavapipe):

| кадр | тетраэдров на осколок | шаг решётки | треугольников |
|---|---|---|---|
| 0 | 54 | 0.28 м | 840 |
| 10 (удар) | 72 → 576 | 0.14 м | 2 820 |
| 40 | 576 | 0.07 м | 10 740 |

Поверхность — **марчинг по тетраэдрам**: для каждого тетраэдра смотрят знаки
поля на 4 вершинах, и по пересечённым рёбрам строятся треугольники; вершины на
рёбрах общие, поэтому меш водонепроницаемый (тест: каждое ребро ровно в двух
треугольниках, объём меша = объёму тела с точностью 1e-3).

## Раскладка

```
c/                     C-ядро Vulkan (instance/device/buffers/pipelines/dispatch)
crates/world/          движок: bcc (ячейки, уровни, дробление), types, sim, vfw
  src/bin/voxelforge.rs  единственный бинарь движка
crates/host/           хост-часть (окно/ввод), пока пустая
shaders/               GLSL compute: физика тел + вода
tests/refsim/          CPU-эталон (оракул) и интеграционные тесты
viewer/                вьюер на WebGL2: BCC-ячейки, орбита, покадровый просмотр
```

`tests/refsim` — не часть движка: это эталон, с которым сверяется GPU-путь
(те же числа: проникновение, остаточная скорость, сон, снос кучи).

## Ячейка и дробление

Решётка BCC в координатах `a/2`: узлы — целые тройки одной чётности (чётные —
угол кубической ячейки, нечётные — её центр). Объём ячейки `a³/2`.

Подразбиение: каждая ячейка → 8 детей с шагом вдвое меньше; суммарный объём
`8 · (a/2)³/2 = a³/2` — сохраняется точно, поэтому масса при дроблении не
меняется и физика не «прыгает».

## Формат `.vfw`

```
"VFW1" | u32 frames | u32 shapes | u32 cells | f32 base
shape:  u32 level | u32 n | n × (f32 x,y,z)
frame:  u32 m | m × (u32 shape | f32 pos×3 | f32 quat×4)
```

Таблица форм растёт по ходу записи: осколок, раздробившийся на 20-м кадре,
получает новую форму, и кадры после него ссылаются на неё. Именно поэтому
в кадре видно, как крупные ячейки становятся мелкими.

## Что приближено (честно)

- **Коллизия осколка — его AABB**, а не точная форма: осколок с рваными краями
  сталкивается как коробка. Картинка верная (тетраэдры двигаются со своим
  осколком), зазоры чуть больше настоящих. Точная коллизия требует выпуклых
  оболочек — следующий шаг.
- **Дробление глобальное**: уровень детализации поднимается у всех осколков
  разом. Пер-осколочное уточнение требует 2:1-баланса и сшивки граней на стыке
  (в RiceEngine это `TetOctMesher` + stitch), здесь этого пока нет.
- **Усечённый октаэдр не делится на 8 своих копий** — попытка дробить ячейки
  теряла 25% объёма. Поэтому примитив — тетраэдр.
- **Вращение блоков выключено** (`inv_inertia = 0`): опрокидывание требует
  контактных манифолдов с несколькими точками на грань.
- **Импульс раскола** — модель: упругая энергия, запасённая до разрушения,
  уходит в разлёт. Импульс не берётся из воздуха — он вычитается из импульса
  снаряда.
- **Сон по смещению**, как в эталоне: иначе крупные осколки «дышат» и не
  засыпают.

## Найденные по пути баги (чтобы не вернулись)

- Солвер мог давать **отрицательный нормальный импульс** — пару, которая уже
  разлетается, он притягивал. В плотном клубке осколков это накачивало энергию
  и за один кадр разгоняло тела до сотен километров в секунду. Теперь импульс
  только отталкивает.
- Порядок обхода контактов был храповиком: импульсы теперь считаются от снимка
  скоростей и применяются один раз с релаксацией.
- Ключ тёплого старта не различал пол и стенки — импульс стенки применялся к полу.

## Сборка

`flake.nix` + `flake.lock` + `Cargo.lock` + `--locked`: через год собирается то
же самое. Шейдеры — `nix build .#spirv`, движку путь передаётся `--shaders`.
По умолчанию прогоны идут на lavapipe (программный Vulkan), GPU не трогается.
