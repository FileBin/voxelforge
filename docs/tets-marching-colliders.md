# Тет для замощения: BCC-решётка (Sommerville)

Источники: Sommerville, «Space-filling tetrahedra in Euclidean space» (Proc.
Edinb. Math. Soc. 41, 1923); Labelle, «Tetrahedral Mesh Generation with Good
Dihedral Angles» (BCC-тет); ar5iv 0806.2332.

## Что это за тет

Делоне-триангуляция **BCC-решётки** (объёмно-центрированный куб) состоит из
**конгруэнтных** тетов — одна из четырёх замощающих конструкций Sommerville.

- рёбра: **два по 1** (короткое ребро между узлами одного типа) и
  **четыре по √3/2** (от узла к центру куба);
- двугранные углы только **60° и 90°**;
- тет **completely well-centered**: центр описанной сферы внутри — для физики
  это идеальный тет, вырожденных конфигураций при деформации нет;
- грани совпадают грань-в-грань с соседями.

**12 тетов на куб** единичного размера (проверка объёмом: объём тета = 1/12).

## Координаты (рабочая формулировка)

Узлы BCC с шагом 1: целые точки `(i,j,k)` и центры кубов `(i+½, j+½, k+½)`.

Куб `[0,1]³`, направление `x`: ребро `(0,0,0)—(1,0,0)` и центры `(½,½,½)` и
`(½,½,−½)`:

```
A1 = (0,0,0)
A2 = (1,0,0)          ребро A1—A2 = 1
B1 = (½,½,½)          |A1B1| = |A2B1| = √3/2
B2 = (½,½,−½)         |A1B2| = |A2B2| = √3/2, |B1B2| = 1
```

Перебор: **3 направления × 4 положения ребра в кубе = 12 тетов на куб**.
Индекс тета — целочисленная арифметика, без пула, без поиска соседей.

## Нумерация в литературе расходится

Sommerville нашёл четыре замощающих тета; в разных работах «№1» и «№2» — разные
из них (в 0806.2332 BCC-тет назван вторым, в «Surface-area-minimizing n-hedral
tiles» №1 — половина треугольной призмы). В коде и доках называем его
**BCC-тет (Sommerville)**, без номера.

## Почему он, а не «1/6 куба»

Ортосхем 1/6 куба тоже замощает пространство, но у него плохие двугранные углы
и он хуже обусловлен при деформации. BCC-тет — единственный из четырёх
completely well-centered и даёт одинаковые теты во всех направлениях.

## Что это значит для марчинга и физики

1. **Marching tetrahedra**: 16 случаев по знаку поля в 4 вершинах, вершины на
   рёбрах кэшируются по ключу ребра. Рёбра у соседей совпадают точно (координаты
   в половинках), поэтому швов нет без всякой «сшивки».
2. **Физика**: состояние тела = 4 вершины на тет в узлах BCC; отдельного
   отображения «частица → тет» не нужно.
3. **Коллайдеры** — прокси-формы (сферы/капсулы), запечённые из поля; сетка тут
   только источник геометрии.
4. **Разрушение** — пометка тетов «разорван» + поле плотности; марчинг даёт
   поверхность осколка без перестройки сетки.

## Порядок работ

1. `tet.rs`: заменить пул на BCC-сетку (12 тетов на куб, индекс арифметический).
   Проверка: объём = число тетов × 1/12, поверхность замкнута.
2. CPU-эталон marching tetrahedra на поле сферы: нет дыр, площадь близка к
   аналитической.
3. Перенос марчинга на GPU по образцу `voxel.comp`/`mesh.comp`.
4. Коллайдеры из поля: жадное покрытие сферами, 32–64 на тело.
